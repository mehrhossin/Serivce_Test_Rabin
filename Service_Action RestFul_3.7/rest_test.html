۲) اعمال شرایط اکشن

PUT /api/nodes/set — ۲ رشته + ۳ بولین.
General: L{c}{s}{p} → L + رنگ(c) + ماسک(s) + چک‌سام(p).
مثال: L11b = رنگ۱(آبی)+ماسک۱(نودهای1..4) · L12c = رنگ۱+ماسک۲(نودهای5..10) · L14e = رنگ۱+ماسک۴(نود12).
ماسک s (۱۶بیتی): بیت۰=نودهای1..4 · بیت۱=نودهای5..10 · بیت۲=نود12 · ترکیبی: 3=1+2, 5=1+4, 6=2+4, 7=همه.
SetKey: S{s}{c} → S + نود(0..12) + رنگ(1..5)، مثال S44 = نود4 نارنجی.
